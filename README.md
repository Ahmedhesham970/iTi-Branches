Description:

ITI Branches is a web application designed to help users easily explore and find all ITI (Information Technology Institute) branches, their locations, and relevant details. Built with Node.js, Express.js, MongoDB/PostgreSQL, and Leaflet for interactive maps, this project leverages geospatial queries to provide fast and accurate results.

Key Features:

📍 Interactive Map: Locate ITI branches visually with custom markers.

🗺️ Geospatial Queries: Uses MongoDB/PostgreSQL geolocation features for proximity-based search.

⚡ Responsive UI: Works smoothly on desktop and mobile.

🛠️ Backend & API: Clean RESTful APIs for managing branch data.

Technologies Used:
Node.js, Express.js, MongoDB/PostgreSQL, Leaflet.js, JavaScript, HTML, CSS

Purpose:
This project demonstrates backend development skills, database geospatial queries, and integration with interactive maps, making it ideal for learning and showcasing full-stack capabilities.
